To publish on GitHub Pages:
1. Create a repository (e.g. `byu-algebraic-geometry`) and push these files to `main` (or `gh-pages`).
2. In repo **Settings → Pages**, choose branch `main` and folder `/ (root)` or `/docs` if you placed files there.
3. Save. GitHub Pages will publish at `https://<your-username>.github.io/<repo>/` (or at your org/site URL).

Optional:
- Use Jekyll templates if you prefer dynamic templates — this site is plain static HTML for simplicity.
- To change contact email or add talk abstracts, edit `seminar.html`.
